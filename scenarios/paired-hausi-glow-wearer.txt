# Hausi, TWO CLIENTS: an upgraded sash's glow as the other machine draws it (LHM-98). This side wears an
# upgraded Deep North sash, the watcher a plain one. Each then looks at the other, face to face.
#
# What it proves. The glow is read off the wearer's ZDO quality, so the watcher's machine must draw this
# side's token lit without ever having held the sash, and must not light its own plain one. And this side
# must not light the watcher's plain sash off its own upgraded one. Code driving the glow from the local
# slot passes every single-player scenario and fails one of those four checks here.
#
# The bench is built ahead and the meeting happens forty metres to the left of the run's starting point,
# so neither stands in a wall or on a roof left by an earlier run. The torch and the pole are only something for `face` to aim at, each beyond the other player, and
# of a kind the shed does not use, because `face` turns to the nearest piece of that name.
